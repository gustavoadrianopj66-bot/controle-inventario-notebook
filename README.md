# 💻 Controle de Notebook — Gestão de Ativos de TI

Aplicação desktop desenvolvida em **Python** para automação do controle, rastreamento e inventário de notebooks e equipamentos de TI.

## 🎯 Problema Resolvido
Substitui o controle manual em planilhas por uma interface gráfica desktop ágil, reduzindo erros de digitação, duplicidade de patrimônio e tempo gasto em auditorias de hardware.

## 🛠️ Tecnologias Utilizadas
* **Python 3**
* **Tkinter:** Interface gráfica nativa (GUI).
* **Pandas & OpenPyXL:** Manipulação estruturada de dados e integração automática com Excel (`.xlsx`).
* **PyInstaller:** Empacotamento em executável (`.exe`) para estações Windows.

## ⚙️ Funcionalidades
* Cadastro rápido de equipamentos (patrimônio, modelo, número de série, colaborador, departamento e status).
* Integração e atualização automática da base de dados em Excel.
* Interface leve, responsiva e pronta para uso operacional em equipes de suporte e field service.

## 🚀 Como Executar
```bash
pip install pandas openpyxl
python controle_inventario.py
```
